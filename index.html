NIO Reactor & Mechanical Sympathy

Single-threaded event loop driven by java.nio.channels.Selector eliminating thread context-switching overhead. Bounded 16MB read and 32MB write buffers guarantee memory safety.

📊

William Pugh SkipList & ZSET

Full 32-level probabilistic SkipList ($p = 0.25$) with distance spans along forward pointers enabling $O(\log N)$ rank, percentile, and range queries (`ZRANK`, `ZREVRANK`, `ZRANGE`).

💾

Dual Persistence & Compaction

Append-Only File (AOF) with configurable fsync policies (`ALWAYS`, `EVERYSEC`, `NO`), crash-resilient truncated log recovery, and atomic online compaction (`BGREWRITEAOF`).

🔄

Master-Replica Replication

1MB circular backlog ring buffer, monotonically increasing 64-bit offsets, and PSYNC protocol handshakes supporting both full and partial resynchronization.

🌐

16,384-Slot Cluster Sharding

Deterministic CRC16-CCITT hash slot partitioning, curly-bracket {tag} routing, and client-side -MOVED redirection frames.

🧠

Probabilistic & Stream Primitives

64-register Flajolet HyperLogLog cardinality estimator, high-density bitfields/bitmaps, and monotonic millisecond event streams with range scanning (`XADD`, `XRANGE`).

bash / powershell
